# 每日资讯博弈指标字典 V1

状态：已与用户确认
版本：`indicator-v1.0.0`
适用范围：A股宏观与行业研究；港股通、美股、日股、韩股仅作市场与行业映射
投资期限：波段 1—3 个月
生成时间：北京时间 07:30，仅A股交易日

## 统一展示与计算规则

每项可量化指标展示四个字段：`最新数据`、`上一日/期`、`同比情况`、`解读`。

- 日频数据的上一期为上一交易日；周频、月频、季频数据分别使用上一周、月、季。
- 同比优先使用发布机构公布的同比值；否则使用去年同期或约252个交易日前数据。
- 利率和收益率的同比变化使用基点（bp）；排名类指标使用排名变化。
- 没有合理同比口径时填 `null`，页面显示“—”，不得强行计算。
- 解读只在机会、风险或接近阈值时出现，使用 `opportunity`、`risk`、`watch`；其余为 `none`。
- 数据源失败时值为 `null`，不得静默用更低等级来源替代。
- 所有历史连接使用 `available_at`，不得使用修订后的未来数据回填历史。
- 所有示例阈值均为初始规则，标记 `threshold-v1`；完成样本外复盘前不称为最优阈值。

初始阈值 `threshold-v1`：`>=85` 狂热/一致乐观并触发红色逆向风险；`70—84` 偏乐观观察；`31—69` 中性；`16—30` 偏悲观观察；`<=15` 极度悲观、仅提示潜在反转窗口。分数需多个成分共振；单一区域不得直接代表全球情绪。

预警规则：单一风险组显著恶化为黄色；两个独立风险组同时触发，或同一组连续2—3个交易日确认，才为红色。数据不足显示灰色，不推断安全。

## M7 波段行业机会

每日仅输出综合得分最高且通过风险门、数据质量门的3个行业，期限1—3个月。

### 四类机会引擎

| ID | 类型 | 核心指标 |
|---|---|---|
| M7-A | 高景气低估值 | 行业产销/订单/价格/利润方向、PE/PB历史分位、景气是否已反映 |
| M7-B | 超跌反弹 | 20/60/120日回撤、相对大盘回撤、MA20/60偏离、ATR标准化跌幅、波动见顶和成交企稳 |
| M7-C | 主线催化 | RPS-20/60、成交占比变化、海外映射、7/30日催化、拥挤与集中惩罚 |
| M7-D | 景气拐点/预期差 | 订单、销量、价格、库存、利用率、排产、出口、资本开支改善但指数未充分反映 |

### V1波段评分

| 维度 | 权重 | 说明 |
|---|---:|---|
| 行业前瞻景气 | 30% | M4直接/间接/桥接，按证据质量收缩 |
| 行业趋势强度 | 18% | RPS-20、RPS-60、相对基准 |
| 估值与赔率 | 15% | PE/PB分位、回撤、均线偏离 |
| 成交与资金关注 | 10% | 成交占比变化、ETF份额变化 |
| 海外映射 | 10% | 直接性、持续性、是否已被国内交易 |
| 宏观政策匹配 | 7% | 增长、信用、利率、汇率与政策环境 |
| 催化 | 5% | 未来7/30/90日可核验事件 |
| 风险惩罚 | 5% | 波动、ATR、拥挤、集中、供给过剩 |

原始分0—100，50为中性。质量调整：`quality = geometric_mean(confidence, coverage, freshness)`，`adjusted_score = 50 + quality × (raw_score - 50)`。覆盖率低于70%或加权质量低于55%时不进入前三，只显示“证据不足”。

每个机会输出：行业、机会类型、调整后得分、核心证据、估值分位、回撤/MA偏离/ATR、海外映射、催化、风险、待确认条件、失效条件、数据质量和模型版本。

## 数据源等级

- E0：法定/原始证据，如政府、央行、监管和交易所正式发布。
- E1：官方结构化或统计数据。
- E2：获授权商业数据。
- E3：聚合、抓取或模型推断，只作辅助并明确标记。

免费原型优先使用E0/E1；AKShare等聚合接口固定版本、记录原始来源和抓取时间，并抽样核对。接口失败时关闭指标，不伪造“主力资金”、日频北向个股持仓或一致预期。

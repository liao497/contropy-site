# 免费数据源矩阵 v2

测试日期：2026-08-19（北京时间）

## 结论

本轮把日报从 19 项指标扩展到 36 项。A股风格/波动、成交集中度、美国科技链、韩国代理、国内宏观、美国信用压力，以及 90 个同花顺行业的 RPS/成交/波动/拥挤数据已经能自动采集。尚未强行补齐的部分是：CME 会议概率、行业估值历史分位、重点产业经营前瞻、海外到国内行业的回测映射、机会 Top 3。

“免费”只表示当前不收取接口调用费，不代表可以忽略上游服务条款、指数版权或再分发许可。AKShare、a-stock-data 等开源项目的代码许可证也不等于其上游行情数据可自由商用或再分发。

## 研究过但本轮未采用

| 来源 | 结论 |
|---|---|
| CME FedWatch | 网页可免费查看，但官方 REST API 有收费表；本轮不采用未授权网页抓取。可另行用期货结算价自行复现模型，但需先核验结算数据许可和方法误差。 |
| 东方财富行业板块接口 | 当前网络环境多次连接失败，不能作为唯一行业主源。 |
| Sina 全A股快照 | 批量接口超时；腾讯快照更稳定，Sina保留为指数历史源。 |
| 金十工业、进出口日历 | 免费接口的最新有效值在测试中明显落后当前报告期，所以没有用于最新日报。 |
| GitHub `CME-FedWatch` | MIT代码，但星数很低且仍依赖CME数据；不直接进入生产采集。 |

## 开源项目参考

- [AKShare](https://github.com/akfamily/akshare)：MIT；本轮用作多家公开网页/接口的传输适配层。测试时约 2.2 万 stars。其代码许可不覆盖上游数据再分发权。
- [a-stock-data](https://github.com/simonlin1212/a-stock-data)：Apache-2.0；测试时约 8.9 千 stars。参考了“腾讯/行情主源 + 独立备源 + 限流降级”的结构，但本项目仍坚持 E1/E3 分层和失败显式留空。
- BaoStock、mootdx：可作为后续A股历史行情备用；在当前指标组合中，尚未比已验证的指数/交易所接口带来更高覆盖。

## 仍待解决的关键缺口

1. 行业估值历史分位：免费接口能拿到申万一级行业当前PE/PB，但与90个同花顺行业无法无损映射，不能假装成同一分类。
2. 五个重点行业的经营前瞻：机器人产量、新能源车销量/电池装机等可从官方月报逐项接；AI、商业航天、自动驾驶仍缺统一、稳定、可复现的免费日/月源。
3. 海外强势板块到A股行业映射：数据已有，映射规则尚未回测，故不自动给机会分。
4. 机会 Top 3：行业行情覆盖已达标，但前瞻与估值输入不足70%，继续关闭，避免仅凭技术指标给出误报。
5. 历史分位：成交集中度和行业拥挤度需要每日归档积累；至少60个交易日后才启用历史极值阈值。

## 运行与失败策略

- 所有时间序列先过滤 `date <= report_date`，防止历史重跑读到未来数据。
- 日频与周频保留各自有效期，不静默前填。
- 单源失败写入 `data_gaps`；不使用旧快照替代最新值。
- 行业历史覆盖低于70%时整组不发布；机会输入覆盖低于70%时不生成 Top 3。
- 当前免费源适合功能验证和个人研究。若用于商用、对外分发或自动交易，必须重新核验每个上游的授权条款。
